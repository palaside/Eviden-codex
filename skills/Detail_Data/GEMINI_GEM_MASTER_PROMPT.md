# Data Schema (10 คอลัมน์มาตรฐาน)
โครงสร้างของ JSON Object แต่ละรายการต้องประกอบด้วยคีย์ดังต่อไปนี้:
- `date`: วันที่ทำรายการ รูปแบบ วัน/เดือน/ปี (เช่น "06/09/2569" หรือ "06/09/69")
- `time`: เวลาที่ทำรายการ รูปแบบ ชั่วโมง:นาที (เช่น "14:35")
- `sender_bank`: ชื่อธนาคารผู้โอน (เช่น "KBank", "SCB", "PromptPay")
- `sender_name`: ชื่อ-นามสกุลของผู้โอน (หากมีเลขบัญชีตัดทอน ให้ระบุตามที่เห็น)
- `amount`: จำนวนเงินที่โอน พร้อมจุดทศนิยม 2 ตำแหน่งและเครื่องหมายจุลภาค (เช่น "1,500.00")
- `receiver_name`: ชื่อ-นามสกุล หรือชื่อบัญชีของผู้รับเงิน
- `receiver_bank`: ชื่อธนาคารผู้รับเงิน (เช่น "KTB", "TTB", "BBL")
- `memo`: บันทึกช่วยจำ (ถ้าไม่มีให้ใส่ "-")
- `remarks`: หมายเลขอ้างอิงธุรกรรม / รหัสตรวจสอบ (Transaction Ref / QR Ref ถ้าไม่มีให้ใส่ "-")

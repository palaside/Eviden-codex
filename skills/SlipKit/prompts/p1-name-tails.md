# P1 — เก็บตกหางชื่อ 3 ตัว

โค้ด Python (stdlib เท่านั้น) มี `STOP_WORDS` ตัดหางชื่ออยู่แล้ว แต่หลุด 3 แบบ:

1. คำว่า `pay` ท้ายชื่อ เช่น `นางสาว ชนัญชิดามนต์ วงค์เขียว pay` → ต้องการ `นางสาว ชนัญชิดามนต์ วงค์เขียว`
2. backtick เพี้ยน เช่น ``นาย ธิติณัฏฐ์` เหมือนขวัญ`` → ลบอักขระ `` ` `` ทิ้ง
3. สระลอย `ฺ` (THAI CHARACTER SARA A, U+0E3A) เช่น `น.ส. ฺจิณห์นิภา` → ลบออก

ให้แก้ฟังก์ชัน `trim_name` + เพิ่ม unit test 3 เคส (เคสละ 1 แบบข้างบน) รัน `python -m unittest` ผ่านหมด แล้วอธิบายว่าแก้ตรงไหนบรรทัดไหน

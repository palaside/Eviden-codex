# Source Of Truth

The active web application for this workspace is the repository root:

`D:\Project\Digital Evi - Codex`

Run the web app from this directory only. The nested `digital-evidence/` directory is an alternate/legacy checkout and is not part of the active runtime unless a task explicitly names it.

The first-phase legal triage boundary is:

`source evidence -> OCR/QR trace -> deterministic legal signal -> human review`

Legal signals are review leads only. They do not prove a violation, change candidate confirmation, or replace review of the source image. External legal research through FourCorners T-LEX is a later, explicit user action and must retain citations and request trace.

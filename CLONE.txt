API endpoints:
- POST /api/upload: รับ files[], เขียนลง RAWFILE/; ยังไม่มี filename sanitization ที่ตรวจพบจากไฟล์ route
- POST /api/slips/extract: multipart หรือ base64 image → Gemini Vision → Zod validate → คืน SlipExtraction + metadata
- POST /api/slips/typhoon: multipart image → Typhoon OCR; ถ้าล้มเหลวคืน fallback: true
- POST /api/slips/validate: validate JSON กับ SlipExtractionSchema
- GET /api/ledger?mode=SLIP: pages router API, ปัจจุบันเป็น mock คืน array ว่าง
Data-flow lifecycle:
1. User drops/selects image files
2. stageIncomingFiles() filters image → detectImageType()
3. CHAT → sliceChatImageLocally(); SLIP → SHA-256 + local cache + jsQR local extractor
4. Background enrichment → /api/slips/extract
5. Batch execute → slips first, chats next, cross-match POI, update manifest/state
6. Render center A4/cover/hash/summary and modal reports
7. PDPA toggle applies maskAccountNumber() / maskPersonName()
